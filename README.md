# UNICEF Report: Global Infant Mortality and Economic Development

**Author:** Tanvee  
**Course:** BAA1030 - Assignment 2  

## Overview
This repository contains a data analysis report exploring the relationship between **Infant Mortality Rate** and key economic indicators such as **GDP per capita** and **Life Expectancy**, using data provided by UNICEF.

The goal of this project is to understand how economic development impacts the health and survival of infants globally. The analysis includes:
- The global distribution of infant mortality.
- The countries with the highest rates of infant mortality.
- The correlation between a country's wealth (GDP) and infant survival.
- The trends over time for selected nations.

## Technologies Used
- **Quarto:** For rendering the final HTML report.
- **Python:** The primary programming language used for data manipulation and visualization.
- **Polars & Pandas:** For data cleaning, reshaping, and joining datasets.
- **Plotnine & GeoPandas:** For creating the visualizations (World Map, Bar Chart, Scatterplot, and Time-series).

## Files in this Repository
- `report.qmd`: The Quarto markdown file containing the narrative and Python code.
- `unicef_indicator_1.csv`, `unicef_indicator_2.csv`, `unicef_metadata.csv`: The raw datasets provided by UNICEF.
- `generate_charts.py`: A standalone Python script to generate the chart images.
- `*.png`: The generated visualization images.
